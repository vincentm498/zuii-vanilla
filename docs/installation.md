## 1. Copie locale des composants (CLI)

C'est la méthode recommandée pour garder un contrôle total sur les styles et les scripts.

### Exécution
Lancez simplement la commande suivante :

```bash
npx zuii-install
```

Pour plus de détails sur les options (dossier personnalisé, mise à jour forcée), consultez la page [CLI Documentation](./cli.md).
